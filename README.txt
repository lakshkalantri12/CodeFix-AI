CodeFix AI - Final Project

Run:
1. Open PowerShell in this folder.
2. Run: python app.py
3. Open index.html in your browser.

Supported languages: C, C++, Python, JavaScript, Java.
The analyzer checks common syntax issues, brackets/symbols, quotes, semicolons,
selected type mistakes, and Python parser errors. Auto-fix is intentionally
limited to corrections that can be made safely by the rule-based analyzer.
